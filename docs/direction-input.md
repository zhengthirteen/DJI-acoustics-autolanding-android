# 方向输入约定

当前是本地生成的有限方向队列，没有麦克风、TCP、UDP 或蓝牙输入。每项持续 500 ms；默认 `WAIT*20`，共 10 秒。序列不会循环，结束后持续零速度悬停，不判断到达，不自动降落。

v1.2 默认使用选项编辑器：选择实际移动方向及持续时间，添加为一段，可排序、改时长、删除，并可使用预设。选择“向北”自动编码为 180，“向东”编码为 270。普通操作无需手输角度，以下数字约定用于内部编码和可选“导入文本”入口。

内部输入仍是“预定目标 → 无人机”的地理偏离角，北 0°、顺时针，与机头朝向无关。控制方向与偏离方向相反：

| 输入 | 表示的偏离 | 实际水平速度方向 |
| --- | --- | --- |
| `0` | 在目标北侧 | 南 |
| `90` | 在目标东侧 | 西 |
| `180` | 在目标南侧 | 北 |
| `270` / `-90` | 在目标西侧 | 东 |
| `WAIT` | 没有方向测量 | 零速度 |

不是把 `0` 当成“向前”，也不是把 `0` 当成“到达”。如需向北移动，应填写 `180`。机头朝东时，同一向北命令会转换为机体向左。

支持英文/中文逗号、分号、空格、换行分隔；`角度*次数` 和 `WAIT*次数` 表示重复。有限角度归一化到 `[0,360)`。拒绝空队列、只有分隔符、NaN、Infinity、非法重复次数、超过 120 项/60 秒或文本超过 4096 字符。

默认水平速度 0.1 m/s，范围 0.05–0.3。预计指令路程 = 数字角度项数 × 0.5 秒 × 速度，不得超过 3 m；WAIT 不计移动路程。这个值不能当作实测距离或地理围栏。

第一次移动可用：

```text
180*2,WAIT*8
```

共 5 秒，前 1 秒向北，随后 4 秒零速度，再进入持续悬停；0.1 m/s 时理想向北位移约 0.1 m。实际位移取决于飞控、惯性、环境和时序，必须目视核验。短序列也不能替代紧急接管验证。

方向切换直接采用新方向，移除了会在反向切换时保留旧方向的圆周 EMA。WAIT 立即清除速度。每个数字方向包括最后一个方向都占满一个 500 ms 时隙；控制循环每 100 ms 检查边界，因此实际切换受调度延迟影响。循环超时直接终止，不追赶播放。

日志时间为 Android 单调毫秒数，非 UTC。未来接阵列必须另行实现源时间戳、序号、过期/失联处理；不能把有限队列完成规则照搬成“网络断流继续等待”。如果阵列原点不等于目标点，只有方位角不能直接换算目标偏离方向，仍需额外估计信息。当前取消了位置/GPS 自动到达演示，降落只由人工单独决定。
