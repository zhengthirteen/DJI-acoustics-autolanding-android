# 第一阶段实验步骤

## 桌面与手机模拟

在仓库根目录执行 `./scripts/test_acoustics.sh`，先确认纯控制测试通过。用 Android Studio 打开 `android-sdk-v5-as/`，构建并安装 `sample-debug.apk`。

打开应用，保持实机开关关闭，使用默认“人工确认”与 `WAIT*120` 启动。无人机模拟初始位置在目标上方、高 4 m，指令保持悬停。点击“确认已到目标正上方”后，应看到 `ALIGNING → HOLDING → LANDING_REQUESTED → LANDING → COMPLETE`；悬停 2 秒后申请降落，之后模拟高度逐步下降至零。SDK 注册失败不会阻止本地模拟。

再尝试：

- 默认 `WAIT*120` 不确认到达：无水平指令，约 60 秒后队列结束并停止，不自动降落。
- 编辑角度队列：确认前测试水平响应，有限队列结束即停止；移动后仍需人工确认位置。
- 附加位置演示：主动切换“位置判据”，使用 `180*40`；从南侧 4 m 出发，约 12.7 秒申请模拟降落。
- 实验中切换页面或锁屏：停止实验，重新进入不会自动重启。

模拟通过只能证明流程和部分算法逻辑，不能证明实机动态性能。

## 实机连接和低速验证

1. 按 [DJI API Key 配置指南](api-key-setup.md) 在 `secrets.properties` 配置匹配的 `APPLICATION_ID` 与 `AIRCRAFT_API_KEY`，重新构建并安装。默认包名为 `com.zheng13.acousticslanding`；本机复用原 Key 时为 `com.zheng13.gradproject`。连接 Mini 4 Pro、RC-N2 和 Android 手机，检查 SDK 注册状态；排查时进入 DJI 诊断页面。
2. 先验证遥测与停止按钮，再在受控环境验证 BODY 速度轴的正负方向、机头朝向变化和控制权交接。模拟队列是开环预设序列，不能视为完成的声学跟踪。
3. 现场无 GPS，由操作员人工起飞并飞到预定降落点正上方。控制要求相对起飞点高度 2–15 m；确认遥控器能随时接管。
4. 保持默认“人工确认”判据和 `WAIT*120`；无需目标经纬度或飞机 GPS 信号。先用悬停队列验证完整链路。
5. 若要测试水平运动，使用短方向队列。模拟角度会造成实际移动，不能判断位置；测试后先停止、人工重新定位到目标上方，再用悬停队列开展降落实验。此模式没有基于位置的边界保护。
6. 勾选“实机发送”，授予手机位置权限，等航向、高度和飞行状态等遥测建立，再点启动。手机权限供 SDK 使用，并不表示要求飞机 GPS 定位。
7. 操作员实际确认已在目标上方后，点击到达确认。悬停 2 秒，释放摇杆成功后发起 DJI 自动降落。若飞控需要最终确认，相应按钮启用；操作员确认落区后点击。
8. 终止时点击停止或遥控器接管。若通信中断、SDK 指令失败，软件不能保证已经取消飞行行为，应依据遥控器和实际飞行状态处理。

位置/GPS 判据是主动切换的附加演示，不用于当前现场实验。该模式需要实际目标 WGS84 经纬度、可用 GPS 信号和位置范围检查，且普通 GPS 不保证亚米精度。

## 摄像头遮挡

声学入口没有图传订阅或相机检测，无需遮挡主相机就能验证应用不依赖图像。若实验要遮挡拍摄相机，只能影响主相机；不要覆盖 DJI 的避障、下视定位、红外或测距传感器，也不要妨碍云台。项目没有关闭飞控内置避障/视觉定位。尤其无 GPS 时，飞控可能仍依靠自身传感器维持稳定，应用“不使用视觉”不等于飞控“不使用视觉”。

## 日志

每次启动新建 CSV，状态面板显示文件路径。默认包名时位于：

```text
/sdcard/Android/data/com.zheng13.acousticslanding/files/experiments/
```

可以用 Android Studio Device Explorer 导出，或自行执行：

```bash
adb pull /sdcard/Android/data/com.zheng13.acousticslanding/files/experiments ./experiments
```

复用旧 Key 并使用 `APPLICATION_ID=com.zheng13.gradproject` 时，日志目录改为 `/sdcard/Android/data/com.zheng13.gradproject/files/experiments/`；导出命令也使用这个包名。以应用状态面板显示的实际路径为准。

`simulation_` 和 `live_` 前缀区分模式。记录方向、状态、北/东位置、相对高度、航向、速度命令和已消费采样数；人工无定位模式的位置列为 NaN，不能推断实际落点。文件头记录模拟队列与 GPS 目标。日志可能含场地坐标，默认不入 Git。

当前已验证：纯 JVM 场景和 Android debug 构建。尚未验证：设备界面、DJI 模拟器、实机轴映射、设备遥测周期、控制权释放、自动降落和最终确认。
