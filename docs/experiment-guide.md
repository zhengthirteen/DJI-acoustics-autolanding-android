# 第一阶段实验步骤（v1.2）

完整电脑/手机操作见 [新手手册](operation-manual.md)。本页用于现场核对。

## 先在本地模拟验证

1. 实机模式关闭，`WAIT*20`、0.1 m/s：10 秒后 `RUNNING → HOVERING`，继续等待不降落。
2. 取消“人工申请降落…”弹窗：仍悬停。单独确认后才进入 `LANDING_REQUESTED → LANDING → COMPLETE`。
3. `180*2,WAIT*8`：前 1 秒向北，之后零速度，最终悬停。模拟位移约 0.1 m。
4. 播放中按顶部紧急制动：终止本次实验，不续播。离开页面也应终止。

## 地面和实机逐级验证

1. 在地面点击“检查/刷新通信”，按 [专项排查指南](connection-troubleshooting.md) 确认注册、设备/飞控连接、遥测和硬件回包，再确认遥控器接管方法；配置方法见 [Key 指南](api-key-setup.md)。地面上启动被拒绝是正常行为。
2. 通过方向/时长选项添加队列或使用预设并保存后，人工起飞并飞到目标上方；相对起飞点高度 2–8 m，保持稳定，电量至少 30%。无 GPS 需可用下视视觉定位。
3. 勾选实机模式，授予手机权限，等稳定遥测/悬停至少 2 秒；点击“已手动定位，启动实机序列…”并确认。
4. 第一轮只用 `WAIT*20`。验证悬停、队列结束仍悬停、紧急制动和交还控制权。发现漂移/异常立即遥控器接管。
5. 第二轮人工重新定位，用 `180*2,WAIT*8`、0.1 m/s。核对方向、停止后的速度和高度；逐次验证其他方位和不同机头，不直接运行长队列。
6. 队列完成后，只有人工申请并确认才降落。若终点不适合降落，交还遥控器调位、人工落地。程序不会自己返回目标。
7. 不需要主相机图像；遮挡实验放在控制与接管验证之后，不能覆盖下视、避障、红外或测距传感器。

## 记录与验收

记录飞机/遥控器固件、手机系统、App 版本、队列、速度、环境、初始/结束位置与高度、是否触发保护、软件制动到实际停止的观察结果。独立视频/现场测量比指令积分更适合判断实际位移。

CSV 通常在 `/sdcard/Android/data/com.zheng13.gradproject/files/experiments/`；若使用默认新包名，则将目录改为 `com.zheng13.acousticslanding`。本机旧包名导出示例：

```bash
adb pull /sdcard/Android/data/com.zheng13.gradproject/files/experiments ./experiments
```

检查：`HOVERING` 后 N/E 命令为零，未经人工确认没有 `LANDING_REQUESTED`；按急停后无续播；高度没有超出允许偏差；遥控器接管有效。日志的 `stop_requested` 仅表明软件已申请停止。实机没有位置轨迹，指令路程不能用作实测距离。

开发测试、主机替身测试与真实飞机验证分别记录，当前验证范围见 [安全审查](safety-review.md)。
